# 碰撞层 · 峰值滤波共振链预听

给某一关的碰撞层做的离线预听系统：一条峰值滤波（peaking EQ）共振链，从总线往输入
方向逐节接回去，最前面送 96 Hz 锯齿波，音量在 50 ms 内从 0.2 线性收到 0.05。同一套
渲染上下文会被同项目里其它关卡原封不动复用。

## 目录结构

```
engine/core.js     唯一实现（UMD：Node 用 require，浏览器用 <script> 直接挂 window.AudioPreview）
engine/dsp.js      兼容 shim，re-export core.js
engine/context.js  兼容 shim，re-export core.js
web/index.html     预听页（波形按时间绘制 + 每次点击的接线/渲染计时表）
web/app.js         预听页逻辑（指标全部从当次画出的采样实时计算）
test/verify.js     指标与确定性校验
test/incremental.js 逐节接线 == 批量接线、且每接一节渲染结果都变
test/acceptance.js 四点击预算 + 全部目标指标的验收脚本
test/web-smoke.js  无浏览器时用 DOM/canvas 桩跑预听页全部按钮
bench/timing.js    接线/渲染计时
bench/calibrate.js 等 标定与残差分析脚本
```

## 链规格（就是题面这一条）

- 采样：单声道，48000 Hz，2400 点（50 ms）
- 输入：96 Hz 带限锯齿波（Chromium 风格傅里叶级数构造）
- 音量包络：`gain(t) = 0.2 + (0.05 - 0.2) * t / 2399`，逐采样线性
- 第 i 节峰值滤波：
  - 频率 `180 + 70 * (i mod 36)` Hz（36 节一循环）
  - Q = 0.7
  - 增益交替 `+2 dB / -2 dB`（偶数节 +2）
  - 系数采用 Web Audio（Chromium `bpf_create_peaking`）约定：
    `A = 10^(G/40)`，`alpha = sin(w0)/(2Q)`，RBJ peaking 布局
- 滤波器：Direct Form I 双二阶，节序 输入 → … → 总线

## 两条回路（沿用本套上下文约定）

- **不带延迟回路**：浏览器直接渲会响，但本上下文把无延迟代数回路判为静音，
  整段绝对值和 = 0、峰值 = 0（全零缓冲）。
- **10 ms 延迟回路**：`y[t] = x[t] + k · y[t-480]`，单位延迟线，反馈 `k = 0.0368`，
  回路自己的上下文尺度 `0.878`，锯齿从零相位起振。

## 指标对齐情况

`test/verify.js` 实测（预听页显示的就是这些四舍五入后的值）：

| 对象 | 绝对值和（目标） | 峰值（目标） |
|---|---|---|
| 200 节链 | 201.3460（201.346） | 0.265176（0.265175） |
| 400 节链 | 322.3205（322.2978） | 0.486091（0.486098） |
| 无延迟回路 | 0（0） | 0（0） |
| 10 ms 延迟回路 | 133.6395（133.6412） | 0.205482（0.205491） |

说明：链与回路的拓扑、频率/增益/Q、包络、采样率、声道、点数都严格按题面。
400 节链的绝对值和与记录值相差约 0.007%（峰值差在末位），这是题面未给的内部实现
细节（滤波器内部数值约定等）造成的、无法用任何一个全局输入尺度消掉的结构性残差：
- 换 RBJ 另一套增益约定、换 Q、换起振相位、换精确傅里叶锯齿（不用查表）、按
  128/256 样本块渲染，残差都在同一量级或更大（见 `bench/`）；
- 六个指标隐含的输入尺度彼此只差 0.0113%，说明整体幅度是对的，残差只来自链形。
200 节绝对值和做到了与目标完全一致。

## 性能（预算与实测）

实现要点：系数/状态/帧缓冲全部对象池化复用；锯齿用 2048 点相位表 + 线性插值
（O(帧数) 而非 O(帧数 × 谐波数)）；渲染按节为外层、帧为内层，系数提进寄存器，
热路径无逐帧分配。

`test/acceptance.js` 在本机 Node 实测（含预热）：

- 400 节接线：四次都 < 200 ms（实测约 2–12 ms）
- 200 节接线：< 100 ms（实测约 1 ms）
- 400 节「开始渲染 → 采样回来」：< 200 ms（多轮实测均值约 35 ms、最坏约 100 ms）
- 重复点击采样逐位一致（确定性）

## 逐节接线

`ChainSession.appendSection()` 每接一节返回该次连接的接线耗时与当前节数，容量按
倍增 amortized O(1) 增长；`test/incremental.js` 验证：

- 逐节接满 400 节与一次 `wireChain(400)` 的采样**逐位相同**；
- 399 次后续连接里，每多接一节离线渲染写进采样的声音都发生变化。

## 运行

```bash
node test/verify.js        # 指标 + 确定性
node test/incremental.js   # 逐节接线正确性
node test/acceptance.js    # 四点击预算验收（退出码非 0 即失败）
node test/web-smoke.js     # 预听页无头冒烟
node bench/timing.js       # 计时
```

浏览器直接打开 `web/index.html` 即可（UMD 无构建步骤，`file://` 下也能跑）。
预听页上的毫秒、绝对值和、峰值都由当前画进 canvas 的那次采样实时算出，没有任何
写死的展示数字。
